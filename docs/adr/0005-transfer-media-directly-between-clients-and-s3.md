# Transfer media directly between clients and S3

The Admin browser uploads MP3 files and the Mobile client streams them directly
to and from S3 using short-lived, object-scoped authorization generated by the
BFF. This avoids routing ordinary media traffic through the Hetzner VPS at the
cost of maintaining strict S3 CORS, signing, and bucket policies; the BFF still
validates uploaded object metadata before making audio playable.
